# Upstream provenance

## Adapted MIT packages (`mattpocock/skills`)

Seven packages were adapted from
[`mattpocock/skills` at `49dd158d1076134a641b33efb035946536778336`](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills).
Each copied folder retains its upstream MIT `LICENSE` and copyright notice.
[registry.json](skills/bootstrap-repo/references/registry.json) records the upstream path for each adapted package, and `skills.lock.json` preserves that provenance alongside SHA-256 hashes of the local files.

| Package | Local adaptation |
| --- | --- |
| `writing-for-agents` | Reworked into an instruction-design and prose-cleanup guide with concrete editing examples, discovery checks, and trap-first sufficiency checks. Retains host-neutral skill mechanics and Codex invocation metadata. |
| `retro` | Loads writing guidance by relative path (`writing-for-agents`), respects session-log retention rules, traces failures to their earliest wrong step, verifies new checks fail on the original mistake, and targets existing repo scripts, linters, and CI jobs. |
| `handoff` | Host-neutral workspace-verified continuation brief; defaults storage inside Git repos to `<git-common-dir>/handoffs/<branch-or-slug>.md` (surviving linked-worktree removal while staying out of `git status` and volatile `$TMPDIR` cleanup), redacts secrets, and records decisions and dead ends. |
| `diagnosing-bugs` | Scoped to non-obvious bugs and performance regressions with neighbor exclusions; bounds probes by discriminating evidence, redacts secrets, tags temporary `[DEBUG-...]` logs for removal, and supports read-only environments cleanly. |
| `tdd` | Targets the smallest stable behavioral seam (`codebase-design` dependency), adds the unverified-red (false-green) trap alongside tautological, mock-coupled, and horizontal-slicing traps, and reports unexecuted checks plainly when execution is unavailable. |
| `codebase-design` | Evaluates module depth by interface complexity versus hidden functionality (avoiding line-count proxies and false-depth mega-methods), checks pass-through layers, temporal splits, and information leakage, and preserves repo vocabulary and justified boundaries. |
| `domain-modeling` | Uses existing repo glossary and ADR locations first, confirms before creating a new `GLOSSARY.md` or `docs/adr/` directory, stays read-only on exploratory questions, and deduplicates the ADR gate. |

`retro` and `handoff` retain explicit-only invocation (`policy.allow_implicit_invocation: false`) in `agents/openai.yaml`; Claude-specific `disable-model-invocation` and unsupported `argument-hint` frontmatter keys were removed. Upstream orchestration, issue-tracker setup, auto-commit flows, and generic implementation prompts were not imported.

## Locally authored packages

The remaining sixteen packages are written locally under the repository's [MIT license](LICENSE). Where a package adapts ideas from a pinned open-source repository or public guide, its `references/sources.md` records the revision, what was adopted, and what was left out; no upstream text was copied.

- **Rust:** `rust-idioms` paraphrases [`rust-unofficial/patterns`](https://github.com/rust-unofficial/patterns) (`36fdd17`, MPL-2.0) and generalizes ideas from [`canonical/rust-best-practices`](https://github.com/canonical/rust-best-practices) (`97c24a9`, GPL-3.0); it does not restate Canonical's house conventions, linking to the guide and recording only locally verified tooling corrections. Reading links are sorted from [`mre/idiomatic-rust`](https://github.com/mre/idiomatic-rust) (`0c4ecad`, CC0). `rust-project-setup` paraphrases the patterns book's `#![deny(warnings)]` anti-pattern. See [rust-idioms sources](skills/rust-idioms/references/sources.md) and [rust-project-setup sources](skills/rust-project-setup/references/sources.md).
- **Review and simplification:** `code-review` adapts verification-evidence checks from [`MiniMax-AI/mcode-stack`](https://github.com/MiniMax-AI/mcode-stack/tree/d520b2b7e864b08ddd62fa3b79c95ec79ec6c2e0) (`d520b2b7`, MIT) and defect-tracing leads paraphrased from [`peteromallet/desloppify`](https://github.com/peteromallet/desloppify/blob/3a7735d531a96b6a226bfbdc9fd662b14195f857/desloppify/languages/_framework/review_data/dimensions.json) (`3a7735d5`, OSNL-0.2). `diff-simplification` compares scope boundaries across pinned skills from `PaulRBerg/agent-skills`, `anthropics/claude-plugins-official`, `getsentry/skills`, and `DietrichGebert/ponytail`. See [code-review sources](skills/code-review/references/sources.md) and [diff-simplification sources](skills/diff-simplification/references/sources.md).
- **Git and GitHub (`change-sequencing`, `github-pr`, `github-issues`):** Draw on Google's "Small CLs" and "CL descriptions" guides (CC-BY 3.0), Conventional Commits 1.0.0, GitHub documentation, `gh` CLI 2.102 behavior, and pinned skills from `microsoft/hve-core`, `mattpocock/skills`, `github/awesome-copilot`, `openai/skills`, `obra/superpowers`, and `MiniMax-AI/mcode-stack`. See [change-sequencing sources](skills/change-sequencing/references/sources.md), [github-pr sources](skills/github-pr/references/sources.md), and [github-issues sources](skills/github-issues/references/sources.md).
- **Agent harnesses and workflows:** `agent-harness-audit` and the subagent boundaries in `agent-workflow-engineering` restructure checklists from [`MiniMax-AI/mcode-stack`](https://github.com/MiniMax-AI/mcode-stack/tree/d520b2b7e864b08ddd62fa3b79c95ec79ec6c2e0) (`d520b2b7`, MIT); both packages ship the upstream notice as `LICENSE-mcode-stack`. See [agent-harness-audit sources](skills/agent-harness-audit/references/sources.md) and [agent-workflow-engineering sources](skills/agent-workflow-engineering/references/sources.md).
- **No adapted upstream:** `python-project-setup`, `python-service-engineering`, `rag-engineering`, `rag-evaluation`, `technical-document-review`, `tui-best-practices`, and `bootstrap-repo`. Where present, their `sources.md` files record scope, verification limits, and related official documentation.
