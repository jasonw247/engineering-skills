# Library request

Create a library named `range_tools` providing `clip(value, lower, upper)`. Return lower for a value below the interval, upper for a value above it, and the value otherwise. Raise ValueError when lower exceeds upper. Support ordinary integer and finite float inputs; no additional numeric types are required.

Use Python 3.9 or later and no runtime dependencies. This is a small reusable library, not a service. Choose the smallest appropriate packaging and validation setup. Work offline using installed tooling. Verify installation and import from outside the checkout, and test observable boundary behavior. Do not fetch dependencies or alter global Python environments.
