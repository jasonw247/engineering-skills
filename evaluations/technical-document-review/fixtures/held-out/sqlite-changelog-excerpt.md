# Bundled SQLite Release Excerpts

- **SQLite 3.35.0 (2021-03-12):** Added support for the `RETURNING` clause on `INSERT`, `UPDATE`, and `DELETE` statements. `STRICT` tables are not present in 3.35.x.
- **SQLite 3.37.0 (2021-11-27):** Added `STRICT` tables (`CREATE TABLE ... STRICT`) for rigid column affinity enforcement.
- **Distribution packaging note:** No Debian or Ubuntu package build manifests are included in this archive; compile-time flags vary by distribution maintainer and release.
