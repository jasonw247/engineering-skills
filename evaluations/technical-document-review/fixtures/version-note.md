# Client migration record

Synthetic archival record, written 2024-05-01 for Client SDK 2.4 on the local
edition. It is maintained as a record of that version, not a current quickstart.
Use the supplied vendor-records.md as the only source.

In SDK 2.4, `Session.resume(token)` resumes a session after process restart [V24].
The API was removed in SDK 3.0 [V30]. For a current integration, confirm the
installed version and its applicable contract before selecting the resume path.

SDK 2.4 local-edition support remains available today [V24].
